# Build Notes

9STriage is a .NET 8 Windows-targeted scanner engine.

## Requirements

- .NET SDK 8
- Windows target runtime for full scanner execution

## Build

```bash
dotnet build scanner-engine/NineSTriage.Engine.csproj -c Release
```

To publish a Windows x64 executable:

```bash
dotnet publish scanner-engine/NineSTriage.Engine.csproj -c Release -r win-x64 --self-contained true
```

## Execution And Tokens

The production scanner requires a valid signed VERIS token file.

The token can be supplied with:

```bash
NineSTriage.Engine.exe --license path\\to\\veris.lic --out output
```

or through the `VERIS_LICENSE_PATH` environment variable.

The dedicated launcher generated by VERIS Central writes a temporary license file and passes it to the scanner. That launcher and its submission token are not part of this repository.

## No Central Included

Building this repository only builds the scanner. It does not build or expose the proprietary VERIS Central analysis service.
